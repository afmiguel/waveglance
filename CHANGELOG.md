# Changelog

Versions follow [Semantic Versioning](https://semver.org/): a new feature
raises the minor number (0.2.0 → 0.3.0), a fix raises the patch number
(0.2.0 → 0.2.1). Each release has a git tag `vX.Y.Z`. The app shows its
version next to the title; hover it to see the git commit of the build.

## 0.18.0 — 2026-11-08

- **FFT as bars**: FFT ▾ → Draw → **Bars** shows one bar per frequency bin,
  like a spectrum analyzer (from the bottom of the plot in dBV, from 0 V in
  V RMS). When the bins are closer than 4 screen points, each screen column
  gets one bar, at the highest level of its bins. The choice is kept for the
  next session; Line is still the default.

## 0.17.0 — 2026-11-08

- **VCD examples** (File ▾ → Open example → Logic (VCD)), made for the
  viewer by `scripts/make-vcd-examples.py`:
  - **CPU bus**: 10 MHz clock, reset, write and read cycles on
    `addr[15:0]` and `data[7:0]` (z between cycles, x before a read
    answers), the strobes and a beat counter.
  - **8-bit DAC**: a 500 Hz sine: the code bus, the load strobe and the
    filtered analog output.

## 0.16.1 — 2026-11-08

- Fix: a file with logic signals only, opened with Y: Div saved from an
  earlier file, showed its lanes squeezed at the bottom of the 8 divisions
  (and the Y menu is off for such a file). The lanes now fill the plot.

## 0.16.0 — 2026-11-08

Buses in VCD files.

- **Buses** (VCD variables with more than 1 bit, up to 64) are shown in
  their own lane, like on a logic analyzer: a hexagon for each value, with
  the value written in it when it fits. Changes too close to see one by
  one show as a filled band; zoom in to see the values. A value with an
  unknown bit (`x` or `z`) shows as "X", in orange.
- **Hex, Dec or Bin**: right-click (or long-press) the bus readout in the
  bottom bar. The choice is kept for the next session.
- Hover over a bus lane: the value at the pointer, and in decimal.
- The time cursors show the bus value at T1 and T2.
- A bus is not a waveform: it cannot be measured, and it is not a source
  for the FFT, Math or Search (the menus say why).
- CSV export writes bus values as whole numbers (`x` if unknown).
- The bit range of a VCD name is kept: `count[7:0]`.
- Fix: in Volts mode, the logic lanes were in the reverse order of the
  file (the first signal was at the bottom).

## 0.15.0 — 2026-11-08

The open items of the UI review, and logic signal rules.

- **Opens on the scope screen.** Files that store the time window the
  scope showed open on it (the record can be longer: the 1013D keeps 30
  divisions for 12 on screen). This applies to the 1013D, Keysight and Rigol
  `.bin`, and Rigol `.wfm`. Fit ▾ → **Scope screen** goes back to it; Fit H
  shows the whole record.
- **Cursors**: the names T1, T2, V1, V2 are at the edges of the plot, and a
  cursor outside the view shows an arrow there (◀T1, V2▲). The grab
  distance is 8 points with a mouse and 20 with a finger. The cursor mode
  is kept for the next session.
- **Trackpad**: a vertical swipe zooms, a horizontal swipe moves along the
  time axis (before, both zoomed).
- **Readouts**: channel names are filled tags, like on the scope. The
  measurement and cursor values have no box (dim name, value in the trace
  colour); the boxes are for the settings in the bottom bar. The samples
  measured (Screen, Record, T1–T2) are named once, above the measurements.
  Negative values use the minus sign "−". 999.7 Hz no longer reads
  "0.9997 kHz".
- **Logic signals only** (VCD):
  - Y, Math and the voltage cursors are off (the menus say why).
  - Only the time measurements can be ticked (Freq, Period, widths, duty).
  - The wheel zooms only the time axis.
  - The FFT shows frequencies only, with levels in dB relative to the peak.
    The span shown is sampled evenly; a warning asks to zoom in when that
    sampling is coarser than the shortest pulse.
  - The search readout names the trace (D0, not CH1).

## 0.14.2 — 2026-11-07

Fixes for digital (VCD) signals, found with a Wokwi logic analyzer file:
- Y: Volts showed volt values (−0.5 V, −2 V…) beside the digital lanes,
  as if the signals were negative. The lanes now have no value scale; with
  only digital signals the axis is "Logic".
- The pointer tooltip in a lane shows only the time.
- Time readouts used the time between the first two points as the
  resolution, so 8.68 µs UART bits read "0 s". VCD traces use the
  `$timescale` (1 ns here); other traces with uneven times use the smallest
  time between two points.
- Rise and Fall are not shown for digital signals (the steps are ideal).
- The maker of "Generated by Wokwi.com" is "Wokwi" (it was "Generated").

## 0.11.0 — 2026-11-07

- **Keysight / Agilent `.bin`** files (InfiniiVision and others, versions

  RigolWFM, BSD-3-Clause).

## 0.10.0 — 2026-11-07

- **CSV files from any oscilloscope** (and other delimited text): Keysight
  (names + units lines), Rigol (sample number with Start/Increment),
  Tektronix (settings in the first columns), Siglent, and this viewer's own
  export (which also gives back V/div, probe and coupling). Separators `,`
  `;` or tab; decimal comma with `;`; current channels (A). The maker is
  shown when the header names it.
- **Format detection with a choice window**: a file is read directly when
  one format is certain; otherwise "Which format is this file?" lists the
  possible formats and all the others. If a file cannot be read, the error
  banner has an **Open as…** button.
- **Large records**: the plot draws only the part in view, about two points
  per pixel; the Math channel and the measurements are cached. A 1-million-
  sample CSV (2 channels) zooms at 60 frames per second in the browser.
- File dialog: .wav, .csv, .txt and all files.

## 0.9.0 — 2026-11-07

Internal restructuring, to make room for other file formats. The app works
as before.

- New internal model (`src/model.rs`): a `Capture` with any number of
  `Trace`s; samples in volts (4 bytes each, evenly spaced, or time/value
  pairs); display settings (V/div, ground position, probe, coupling); input
  limits for clipping. No FNIRSI-specific fields any more.
- File formats in `src/formats/`: each format says how sure it is that a file
  is its own (`probe`) and reads it (`read`); `formats::open` tries them from
  the most to the least sure. FNIRSI DPOX180H and 1013D/1014D are the first two.
- The app handles N channels (colours for CH1–CH4) instead of exactly CH1 and
  CH2: OSD, measurements, cursors, FFT, search, reference, CSV export.
- Math: choose A and B among the channels (A + B or A − B).
- `app.rs` (3400 lines) split into modules: menus, readouts, plot, input,
  dialogs, actions and number formatting.

## 0.7.0 — 2026-11-07

- **Σ Math ▾**: CH1 + CH2, CH1 − CH2 or CH2 − CH1, sample by sample. The
  MATH trace is measured like a channel; click the MATH readout to hide it.
- **⌕ Search ▾**: rising edges, falling edges or glitches in the whole record
  of CH1 or CH2; marks on the bottom edge, Previous/Next (keys [ and ])
  centre the view on each event.
- Measure → **Statistics per cycle**: a floating window with mean, min, max,
  σ and number of cycles of the time measurements.
- **Print window**: white background (recommended, with the reason) or black;
  the screen changes only for the picture and comes back by itself.
- Toolbar: each button wraps to the next row as a whole (no button is cut
  off at the right edge); menu text wraps normally.

## 0.4.0 — 2026-11-07

  samples shown in the time plot. Windows: Rectangular, Hanning, Hamming,
