# Example files (FNIRSI DPOX180H)

Captures saved on a real FNIRSI DPOX180H by the author of this viewer, for the
File → Open example menu. They are not changed.

| File | Content |
|---|---|
| `square-1khz.wav` | A 1 kHz square wave on CH1: 1 V/div, DC coupling, 500 µs/div, 48000 samples at 4 MS/s, trigger Auto, rising edge, CH1. |
| `two-channels.wav` | The same square wave on CH1 (1 V/div, DC) and on CH2 (2 V/div, AC coupling): 24000 samples per channel at 2 MS/s. The CH2 signal is small. |

They are part of this project, under the same terms as its source code.
