# Example files (Rigol)

These files are captures from real Rigol oscilloscopes. They come from the
RigolWFM project by Scott Prahl, <https://github.com/scottprahl/RigolWFM>
(`tests/files`, commit 9e6f993).

| File | Oscilloscope | Format |
|---|---|---|
| `DHO1074.bin` | DHO1074 | Rigol `.bin` (RG03) |
| `MSO5000-A.bin` | MSO5000 series | Rigol `.bin` (RG01) |
| `DS2072A-1.csv` | DS2072A | CSV saved by the scope |
| `DS1102E-D.csv` | DS1102E | CSV saved by the scope |
